## 一、题目信息
- **平台**: CTFHub
- **题型**: Web
- **考点**: 字符型SQL注入、引号闭合、注释符、UNION联合查询

## 二、解题思路与踩坑记录

页面和整数型注入一样，一个ID输入框，一行红字显示实际执行的SQL。区别在于后端把输入包在单引号里：

```sql
select * from news where id='输入'
```

数字型直接拼，字符型必须先闭合引号再注释掉多余部分，否则语句一定报错。这是两类题唯一的区别，但也是最容易卡住的地方。

**踩坑一：引号用了中文标点**

输入`999‘`看似闭合了，实际用的是中文左引号，编码不同，数据库不认。表现是页面空白，红字看起来却完全正常。判断方法：英文引号是竖直的'，中文引号是弯的‘或’。切换英文输入法，或者直接复制英文引号。

**踩坑二：漏写闭合引号**

输入`999union select 1,2`，红字变成`id='999union select 1,2--'`，整串被当成一个字符串去查，自然查不到。闭合引号是payload的第一个字符，不能省。

**踩坑三：裸的--不是注释**

写成`1' order by 3--`，--后面紧跟程序补上的引号，不是空白字符，MySQL把--当成两个减号参与运算，语句报错。表现是页面空白，很容易误判成“第3列不存在”。

正确写法是--后面带空格，或者直接用#：

```
1' order by 3#
1' order by 3 -- 
```

**踩坑四：地址栏里的#被截断**

在地址栏直接写`?id=999'union select 1,2#`，#会被浏览器当成页面内锚点，不发送给服务器。红字结尾只剩一个引号，说明#丢了。

地址栏里必须写成%23，或者改用页面上的输入框，表单提交会自动编码。

最终用井号注释跑通整条链路。

## 三、解题步骤

1. **验证闭合**: 输入1正常，输入1'后结果区空白，说明单引号被拼进语句。
2. **闭合与注释**: 输入`1'#`，数据恢复，确认闭合与注释都生效。
3. **确定列数**: 依次输入`1' order by 2#`与`1' order by 3#`，前者有数据、后者空白，列数为2。
4. **定位回显位**: 输入`999' union select 1,2#`，结果区显示ID: 1、Data: 2。
5. **查库名**: 输入`999' union select 1,database()#`，返回库名sqli。
6. **查表名**: 查询information_schema.tables，限定table_schema=database()，返回flag和news。
7. **查字段名**: 查询information_schema.columns，限定table_name='flag'，返回字段名。
8. **取数据**: 查询flag表对应字段，得到ctfhub{替换为你的flag}。

## 四、总结与反思

1. **字符型与数字型的区别**: 数字型输入直接进入语句，字符型被引号包裹。前者不需要闭合，后者必须先用引号闭合，再用注释符处理剩余部分。
2. **注释符的作用**: 闭合之后，程序原有的收尾引号会变成孤立字符，必须注释掉。注释符有三种：#、--加空格、/* */，MySQL三种都支持，通用性最好的是--加空格。
3. **为什么用不存在的id**: 页面只显示结果集第一行。用999这类查不到的id，UNION伪造的那一行才是唯一一行，不会被原始数据遮住。
4. **UNION的前提**: 两条查询列数一致、类型兼容。所以必须先order by数列数。
5. **报错被隐藏时的判断**: 页面不显示错误信息，语法错和查不到数据都表现为空白。要靠“确定的空结果”和“确定有数据的id”做对照，才能区分。
6. **输入方式的影响**: 地址栏里#会被截断、引号可能被输入法替换，用输入框或编码后的URL更稳。

## 五、问题与解答

**问：为什么要闭合引号。**

答：后端把输入包在单引号里，形成`id='输入'`。你输入的内容本来只是字符串的一部分，写一个单引号提前结束这个字符串，后面的内容才会被当成SQL代码解析。这就是把数据变成代码的过程。

**问：闭合之后为什么还要注释。**

答：原语句末尾还有一个程序写的引号，你闭合之后它变成孤立字符，语法报错。注释符把这一行剩下的内容全部忽略，语句才完整。

**问：#和--有什么区别。**

答：#是MySQL专用，注释到行尾，不需要空格；--是标准SQL，后面必须跟空白字符。URL里#必须写成%23，否则被浏览器当锚点。

**问：为什么用999而不是1。**

答：页面只打印结果集第一行。id=1有数据，UNION的伪造行排在第二行看不到；999没有数据，伪造行成为唯一一行。

**问：这些payload需要背吗。**

答：不需要。要记的是顺序：判断类型、闭合注释、数列数、找回显、查库表字段、取数据。语句可以整理成模板，用的时候替换表名和字段名。

**问：为什么输入框和地址栏的结果不一样。**

答：编码方式不同。表单提交由浏览器自动编码，井号和引号都会正确转义；地址栏里井号会被当成锚点截断，引号还可能被输入法换成中文标点。
