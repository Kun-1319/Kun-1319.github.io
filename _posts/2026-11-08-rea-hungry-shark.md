## 一、实验目标

我想用自己的小米手机测试《饥饿鲨：进化》的离线金币和钻石，看看能不能调整余额，再走游戏内的流程购买鲨鱼或皮肤。样本只用于我自己的测试。

一开始我问的是「GitHub 有没有现成的破解版」「我只自己玩、不外传，会不会违法」「不解除付费墙怎么破解」「离线操作会被发现吗」。后来我把问题缩小到一个能验证的目标：先查清这个版本怎样读取和保存余额，再分别看能不能启动、能不能买东西、重开后结果还在不在。法律和授权问题我单独考虑，下面记录的是实际操作和手机上的表现。

## 二、实验环境

| 项目 | 配置 |
|---|---|
| 电脑 | Windows，使用 PowerShell |
| 手机 | 我自己的小米安卓手机 |
| 实际操作 | DeepSeek Harness（DSH） |
| 指令整理与监督 | Codex -GPT6-Astra|
| 手机原有版本 | 小米渠道版《饥饿鲨：进化》9.16.93 |
| 本次修改测试样本 | 国际版《饥饿鲨：进化》6.8.2 |
| 手机连接工具 | Android SDK Platform-Tools 中的 ADB |

我问过「《进化》和《世界》有什么区别，下哪个」，最后选了《进化》。后来才知道，《进化》也有不同渠道的包。我手机原来装的是 9.16.93，DSH 实际拿来做修改实验的是国际版 6.8.2。下面的启动和闪退结果都对应 6.8.2。

## 三、操作过程

### 1. 先搞懂 APK 和 ADB

我一开始没装游戏，电脑里也没有安装包，就问 Codex「APK 是啥」「为什么要安装，直接逆向不可以吗」。

APK 是安卓应用的安装包。拿到文件后，可以先在电脑上看里面的代码和资源。手机主要用于取到我实际安装的包，以及验证游戏运行时的表现。

后来我又问「ADB 是什么」。在这次实验里，它负责让电脑通过 USB 和手机通信。第一次让 DSH 检查时，系统 PATH 和指定工具目录里都找不到 ADB，所以设备和包名检查没能执行。更早准备工具时，安装脚本还遇到过 `pwsh` 缺失、GitHub 直连返回 HTTP 500 的问题。

我把下一条指令缩成一句：

> 从安卓官网下载 Windows 版 ADB，解压到工具目录。确认能运行，告诉我版本号后停下。

### 2. 让 DSH 执行，让 Codex 核对

我问过 Codex「给你什么模型才能省用量同时高质量完成任务」，也问过「我可以直接让 DSH 逆向这款游戏，然后装到我的手机上吗」。我最后采用的分工是让 DSH 选命令、执行和汇报，让 Codex 看证据、指出哪里跑偏。涉及手机界面的操作由我自己完成。

最早讨论时，DSH 提到余额可能保存在 `shared_prefs`。我问 Codex「这还没开始逆向吧，哪来这些信息？」于是我把存档位置、字段名和本地余额是否有效都记成待验证的假设。后面即使看到余额变了，也还要判断它是程序读出来的数，还是确实写进了存档。

### 3. 在手机上重试安装

DSH 把国际版 6.8.2 的测试包推到了手机。第一次通过 ADB 安装时，小米手机的「USB 安装」没有打开。我在手机上打开后回复 DSH「打开了」，它重试并报告安装成功。

接下来游戏很快退回桌面。DSH 查看崩溃日志，报告堆栈涉及 `libmono.so`。到这一步，我知道 APK 已经装进去了，接下来要排查的是游戏为什么没能正常运行。

### 4. 用原版做对照

我问 Codex「你在看吗」，又告诉它有必要可以插手。它看到 DSH 已经在做对照，就继续观察，让 DSH 先跑完这一轮。

DSH 在同一台手机上启动了未修改的国际版 6.8.2，并报告原版能启动。这让排查范围缩小到了修改内容和重新打包过程。之后，DSH 保留原来的 `Update()` 逻辑重新测试，还是闪退。它又开始测试让工具把原 DLL 读入再写出，保持游戏逻辑原样，看看工具重写文件本身是否会引入问题。

中间我还报过一次「玩着玩着闪退了」。这次已经进了游戏，和前面一启动就退的现象不同。当时我没记下手机上跑的是哪个测试包，所以这次异常单独记录。

## 四、遇到的问题与处理

| 问题 | 原因与处理 |
|---|---|
| 没有 APK，不知道从哪开始 | 先区分电脑上分析安装包和手机上运行测试，再记录实际使用的版本 |
| 工具链准备卡住 | DSH 报告 `pwsh` 缺失，GitHub 直连返回 HTTP 500。我把 ADB 单独拆成一步，让 DSH 从官方来源获取并验证 |
| 找不到 ADB | 首次检查的两处路径都没有 ADB，设备检测和包名核对因此跳过 |
| 小米手机拦住 USB 安装 | 我打开手机上的「USB 安装」，DSH 再重试 |
| 修改包装上后启动闪退 | DSH 查崩溃日志，并在同一台手机上启动未修改的 6.8.2 作对照 |
| 保留 `Update()` 后仍闪退 | DSH 继续测试只重写 DLL 的情况，尝试缩小问题范围。记录里没有足够证据确定根因 |
| 运行中途闪退 | 我记录了现象，但漏记当时的测试包，暂时无法归到某个构建 |
